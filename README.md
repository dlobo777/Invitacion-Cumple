- 🎭 Animaciones: nubes, globos, confetti
- 📱 100% responsive
- 🎮 Controles interactivos

## 📱 Cómo Funciona

1. Al abrir el link, aparece una pantalla de inicio
2. Toca en cualquier lugar para comenzar
3. La música se reproduce automáticamente
4. Navega entre slides con los controles o gestos
5. Comparte el link con todos los invitados
